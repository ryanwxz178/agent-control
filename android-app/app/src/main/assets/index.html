开启电脑连接

设置一次，之后从手机连接

在 Mac 上操作

  1. 打开远程登录

    系统设置 → 通用 → 共享 → 远程登录。打开开关，在“允许访问”中添加你自己的电脑用户。

  2. 找到地址与用户名

    系统设置 → Wi-Fi → 当前网络的“详细信息” → TCP/IP，查看 IP 地址。远程登录页面的 ssh 用户名@地址也可参考。

    不确定用户名时，在电脑终端运行：

    whoami
  3. 回到手机填写

    地址填电脑的 IP；用户名填刚查到的短用户名；端口通常为 22；密码填该用户的电脑登录密码。

如果要控制桌面应用

保持电脑已登录且解锁。首次使用按系统提示给 sshd-keygen-wrapper / osascript 开启辅助功能，以及自动化 → System Events。纯 CLI 通常不需要这些桌面权限。

在 Windows 电脑上操作

  1. 安装 OpenSSH 服务器

    设置 → 系统 → 可选功能（部分版本在“应用”中）→ 添加功能，搜索并安装 OpenSSH Server。也可在管理员 PowerShell 中运行下方命令。

    $cap = Get-WindowsCapability -Online -Name OpenSSH.Server* if ($cap.State -ne 'Installed') { Add-WindowsCapability -Online -Name $cap.Name }
  2. 启动服务并允许局域网连接

    继续在管理员 PowerShell 运行。防火墙规则仅允许同一局域网。

    Start-Service sshd Set-Service -Name sshd -StartupType Automatic $rule = Get-NetFirewallRule -Name 'OpenSSH-Server-In-TCP' -ErrorAction SilentlyContinue if ($rule) { $rule | Set-NetFirewallRule -Enabled True -RemoteAddress LocalSubnet } else { New-NetFirewallRule -Name 'OpenSSH-Server-In-TCP' -DisplayName 'OpenSSH Server' -Direction Inbound -Action Allow -Protocol TCP -LocalPort 22 -RemoteAddress LocalSubnet }
  3. 找到用户名和 IP

    在电脑 PowerShell 运行下面的命令。使用当前网络适配器的 IPv4 地址；登录密码要用账号密码，Windows Hello PIN 不能代替。

    $env:USERNAME ipconfig Get-Service sshd
天翼云等 Windows 云电脑

手机和云电脑不在同一网络时，两端登录同一个 Tailscale 网络，地址填云电脑的 100.x 地址；云电脑还需给手机的 Tailscale IP 放行 SSH。不要填云桌面画面里不可达的内网地址。

下面命令需把示例地址换成手机在 Tailscale 中的实际 IP，再由管理员执行：

New-NetFirewallRule -Name 'Orca-Pocket-Tailscale-SSH' -DisplayName 'Agent Control SSH' -Direction Inbound -Action Allow -Protocol TCP -LocalPort 22 -RemoteAddress '手机的Tailscale-IP'

控制 WorkBuddy / 豆包桌面还要运行 Windows Bridge，保持同一用户桌面登录、解锁。RDP 断开或锁屏可能影响桌面操作；Windows 托管 WorkBuddy CLI 尚未接入手机完整链路。

在 Linux / WSL 上操作

  1. 安装并启动 SSH 服务

    Ubuntu / Debian 可在电脑终端运行；其他发行版按系统的 OpenSSH 文档设置。

    sudo apt update sudo apt install openssh-server sudo service ssh start
  2. 查询连接信息
    whoami hostname -I

    使用手机能访问的地址与该 Linux 用户的登录密码。若启用防火墙，还需允许可信网络访问 SSH。

WSL 的区别

WSL 的内部 IP 通常不能从手机直接访问，需要额外配置网络或端口转发。控制 Windows 桌面请选择 Windows OpenSSH；连接 WSL 只操作其中的 CLI。

仍然连不上？

“连接拒绝”：检查 SSH 服务和端口。超时：检查地址、网络与防火墙。认证失败：检查用户名和账号密码。首次连接时，核对电脑的 SSH 主机指纹再确认。

macOS WorkBuddy 托管 CLI 还需桌面已登录，并完成一次任务以初始化托管服务。退出重开后可能需要再次初始化。重新连接不会自动重发之前的任务。

接入方式与权限说明

默认先使用 CLI，确认尚未执行任务且启动失败后转桌面。直接桌面会跳过 CLI；仅 CLI 会保留登录错误，不自动切换。

桌面应用沿用电脑现有权限。macOS 需要解锁及桌面控制授权；Windows 需要同用户桌面桥接运行。自动调度可安排多个 Agent 协作，桌面操作依次执行。
